# Noto Sans

`NotoSans.ttf` is the unmodified Noto Sans variable font from Google Fonts:

https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth,wght%5D.ttf

Copyright 2022 The Noto Project Authors. Distributed under the SIL Open Font
License 1.1; see the bundled `OFL.txt`. No system font installation or font
download is needed when running AOPi.

The FreeType extension renders this font at the chosen UI size. When the
framebuffer is denser than the logical window, glyphs are generated at the
higher resolution and displayed at their intended logical size.
